# 01. Project Overview & Roadmap

## 1. Executive Summary
This project aims to build a modern, high-performance, and scalable digital entry point for an Early Childhood Education institution (TK).
Built using a **Composable / Decoupled Architecture** on Vercel's Free Tier, the platform delivers a premium, vibrant, yet highly professional public experience while maintaining absolute zero infrastructure cost.

## 2. Core Philosophy & Scalability Paradigm
- **Public-First, Foundation-Ready:** Phase 1 focuses purely on public discovery, trust-building, and inquiry capture. However, the database and API models are architected to scale into complete parent portals, billing systems, and daily activity tracking without refactoring the core codebase.
- **Leverage Third-Party Modules:** Never build from scratch what can be integrated for free. Utilize best-in-class SaaS free tiers (Sanity, Supabase, Resend, Cloudinary) to keep development lean and fast.

## 3. Product Roadmap

### Phase 1: Public Discovery & Lead Capture (Current Scope)
- High-converting, SEO-optimized landing page.
- Interactive program descriptions, facility highlights, and teacher profiles.
- Integrated lead generation form (Inquiries & Visit Scheduling) linked to automated email notifications and WhatsApp integration.

### Phase 2: Admission & CRM (Future)
- Digital PPDB (Penerimaan Peserta Didik Baru) student enrollment forms.
- Applicant status tracking and document upload pipeline.

### Phase 3: Parent Engagement & Operations (Future)
- Authenticated Parent Dashboard via Supabase Auth.
- Daily activity updates, attendance logging, and tuition billing/payment gateway integration.
