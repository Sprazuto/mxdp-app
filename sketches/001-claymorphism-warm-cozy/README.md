## Variant: Warm Cozy Claymorphism

### Design stance
Earthy, layered claymorphism with warm neutrals — feels like a favorite blanket. Cozy, inclusive, parent-trusted.

### Key choices
- **Layout:** Centered, card-based "bubbles", generous padding, soft reveals
- **Typography:** DM Sans (body) + Maven Pro (display) — modern, warm, excellent readability
- **Color:** Cream/sand base, peach/coral/sage/lavender/terracotta — warm analogous + one cool accent
- **Interaction:** Gentle lift, border glow on focus/hover, sparkle ambient animation, dark mode support

### Trade-offs
- Strong at: Parent trust, cozy/calm vibe, dark mode ready, inclusive (low motion, high contrast), longevity
- Weak at: Immediate "wow" factor, high-energy conversion, very young kids (needs more contrast)

### Best for
- Parent decision-makers, subscription/long-term retention, bedtime/quiet apps, brand building
